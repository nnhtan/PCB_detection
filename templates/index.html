      Tài Liệu API Backend Python

      Hệ thống cung cấp đầy đủ các chuẩn REST API JSON để nhúng vào dây chuyền sản xuất, hệ thống IoT hoặc ứng dụng mobile/web.

      POST /api/inspect — Kiểm tra mạch PCB toàn diện (So sánh mẫu chuẩn)

      Tham số: Gửi file ảnh (multipart image) hoặc JSON {"image_base64": "...", "conf": 0.25, "tolerance_ratio": 0.045}.

      curl -X POST http://localhost:5000/api/inspect \ -F "image=@2.jpg" \ -F "conf=0.25" \ -F "tolerance_ratio=0.045"
      # Python Script gọi API Kiểm tra mạch PCB import requests url = "http://localhost:5000/api/inspect" files = {"image": open("2.jpg", "rb")} data = {"conf": 0.25, "tolerance_ratio": 0.045} response = requests.post(url, files=files, data=data) result = response.json() print("Kết quả:", result["verdict"]) # "OK" hoặc "FAULTY" print("Khớp:", result["stats"]["matched"]) print("Thiếu:", result["stats"]["missing"]) print("Độ trễ:", result["latency_ms"], "ms")
      POST /api/detect — Nhận diện linh kiện YOLO thuần túy
      curl -X POST http://localhost:5000/api/detect \ -F "image=@2.jpg" \ -F "conf=0.25"
      GET /api/info — Lấy thông tin model, GPU, danh sách class
      curl http://localhost:5000/api/info
